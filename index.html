Luna

Задача

Клиенты пишут в салон в любое время суток, а администратор физически не может отвечать ночью и в нерабочие часы.

Решение

RAG-бот на n8n отвечает на вопросы по базе услуг и цен, сам предлагает время и записывает через Google Calendar, заявка сразу падает в Bitrix24.

Результат

Клиент может записаться в два часа ночи без участия администратора, сделка в CRM создаётся автоматически.

  • n8n
  • RAG
  • Qdrant
  • OpenRouter
  • Google Calendar
  • GreenAPI
  • Bitrix24

Iron House

Задача

Нужно было проверить, переносится ли архитектура Luna на другую нишу и другую CRM без пересборки с нуля.

Решение

Тот же RAG-движок адаптирован под фитнес-клуб - база абонементов и тренеров, запись на индивидуальные тренировки, интеграция с amoCRM вместо Bitrix24.

Результат

Полный цикл диалог, запись в календарь, сделка в amoCRM, уведомление админу подтверждён живым прогоном.

/ Python

Агент поиска работы

Задача

Вручную каждый день пересматривать десятки вакансий на hh.ru и Хабр Карьере под конкретный стек - трата времени.

Решение

Python-скрипт парсит вакансии, Claude оценивает совпадение по стеку и формирует топ-15, бот присылает подборку в Telegram каждое утро в 9:00 по расписанию.

Результат

Подборка приходит автоматически, без ручного мониторинга площадок.

  • Python
  • Claude API
  • BeautifulSoup
  • Telegram
  • launchd

TaskMaster

Задача

Задачи руководителя разбросаны по переписке и голосовым сообщениям, ничего не структурировано.

Решение

Telegram-бот принимает текст и голос, классифицирует задачу через Gemini и создаёт карточку в Notion, утром присылает сводку по горящему.

Результат

Голосовая заметка превращается в структурированную карточку без ручного заполнения полей.

/ CRM

CRM-интеграция

Задача

Заявка из мессенджера потенциального клиента нигде не фиксируется как сделка, менеджер узнаёт о ней постфактум.

Решение

Событие-триггер через HTTP-запрос к REST API создаёт сделку напрямую в Bitrix24 или amoCRM с нужными полями.

Результат

Сделка появляется в CRM в момент заявки, без промежуточного шага "кто-то вручную перенёс".

  • amoCRM
  • REST API
  • Webhooks
  • OAuth2

Путь в автоматизацию

С конца 2022 плотно занимаюсь искусственным интеллектом: курсы Kaggle и Google по AI-агентам, курсы по n8n и промпт-инжинирингу.

С марта 2026 сфокусирован только на ИИ-автоматизации. Claude Code - основной инструмент, n8n и Google Antigravity в связке.

Каждый день изучаю что-то новое и не боюсь тестировать. Так как технологии меняются стремительнее, чем когда-либо прежде, держать руку на пульсе считаю необходимым.

С июня веду блог про ии-автоматизацию, где показываю путь без прикрас - грабли, мысли и рабочие кейсы. Блог - это творчество. Автоматизация - ремесло.

Цель простая и амбициозная: стать одним из топовых ИИ-автоматизаторов. За этим будущее, и я хочу быть в нём не наблюдателем, а тем, кто строит и приносит реальную пользу.
