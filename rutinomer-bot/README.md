# Рутиномер

Telegram-бот-диагностика автоматизации бизнеса. За 5-10 минут разбирает бизнес
человека, считает уровень автоматизации по шкале /10 и подводит к созвону.

Сделан для [Евгения Ткаченко](https://tkachenko-ai.com), специалиста по
AI-автоматизации. Модель - Claude (Anthropic), стек - Python + aiogram, без n8n.

## Как работает диалог

| Шаг | Что происходит | Кто отвечает |
|-----|----------------|--------------|
| 0 | Согласие на обработку данных кнопкой | статичный текст |
| 1 | "Чем занимаешься?" - открытый вопрос | статичный текст |
| 2 | "Что бесит?" - открытый вопрос или кнопка "Не знаю" | статичный текст |
| 3 | 4-6 вопросов кнопками, сгенерированных под нишу | Claude, структурой |
| 4 | Оценка X/10, похвала, провалы, 2-3 пункта что автоматизировать | Claude, текстом |
| 5 | Два оффера кнопками, сбор контакта | статичный текст |

Оценку считает **бот, а не модель**: сумма баллов / максимум * 10, округление
до целого (`bot/llm.py::score_to_ten`). Модель получает готовую цифру и не
имеет права ее пересчитывать. Это требование брифа - чтобы оценка была
воспроизводимой, а не "на глаз".

Максимум считается по лучшему варианту каждого вопроса, а не по `2 * N`: модель
иногда не дает варианта на 2 балла, и тогда `2 * N` наврал бы в минус.

## Лимиты и оплата

Первая диагностика бесплатная, дальше 3$ звездами Telegram. Проверка по
`telegram user_id` в базе, не в промпте.

Оплата сделана на Telegram Stars, потому что для цифровых товаров внутри
Telegram это единственный разрешенный способ: `currency="XTR"`,
`provider_token` пустой, `amount` - само число звезд без домножения на 100.
Попытка начисляется **только** по апдейту `successful_payment`, с защитой от
дублей по `telegram_payment_charge_id`. Возврат - `/refund <user_id> <charge_id>`
(только для админа).

`PRICE_STARS=188` - это ~3$ по курсу ~0.016$ за звезду. Курс меняется и
зависит от того, где человек покупал звезды (через App Store дороже), так что
это переменная окружения, а не константа в коде.

## Куда падают лиды

1. Уведомление Евгению в личку (`ADMIN_CHAT_ID`).
2. Запись в SQLite - на случай, если уведомление не дошло.
3. Выгрузка CSV командой `/leads`.

## Запуск локально

```bash
git clone https://github.com/Evgeniy-Tkachenko-Ai/rutinomer-bot.git
cd rutinomer-bot
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env      # заполни BOT_TOKEN и ANTHROPIC_API_KEY
.venv/bin/python -m bot.selftest    # проверка связки с Claude, один вызов
.venv/bin/python -m bot
```

`ADMIN_CHAT_ID` узнается так: запусти бота и напиши ему `/whoami`.

## Команды

| Команда | Кому | Что делает |
|---------|------|------------|
| `/start` | всем | начать диагностику |
| `/help` | всем | подсказка |
| `/delete` | всем | удалить все свои данные |
| `/whoami` | всем | показать свой chat_id |
| `/stats` | админу | сводка по воронке |
| `/leads` | админу | выгрузка лидов в CSV |
| `/refund` | админу | вернуть звезды за платеж |

## Тесты

```bash
.venv/bin/python -m pytest -q
```

Покрыто то, что можно проверить без сети: скоринг, границы шкалы, валидация
структуры теста от модели, чистка длинных тире. Сам вызов Claude проверяется
через `python -m bot.selftest`.

## Безопасность

Секретов в репозитории нет и быть не может: все читается из окружения
(`bot/config.py`), `.env` в `.gitignore`, в репозитории только `.env.example`
с пустыми значениями. Перед публикацией код проверен на утечки ключей.

Если ключ все же где-то мелькнул - отзывай сразу: бот у @BotFather
(`/revoke`), Claude в console.anthropic.com. Переписать историю git дешевле,
чем платить за чужие запросы к модели.

## Структура

```
bot/
  config.py      конфиг из окружения, секретов в коде нет
  db.py          SQLite: пользователи, прохождения, лиды, платежи
  llm.py         обертка над Claude, скоринг, валидация теста
  prompts.py     системный промпт (текст брифа) и задачи по шагам
  texts.py       все статичные тексты
  keyboards.py   кнопки и цена в звездах
  states.py      FSM-шаги диалога
  health.py      /health и самопинг против засыпания
  selftest.py    проверка связки с Claude одной командой
  handlers/      start, diagnostic, offer, payments, admin
```
